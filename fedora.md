# My Fedora edc

Home Setup
- Fedora Linux 44 (Workstation Edition) 

This document supports the bash installation scripts provided in [edc-configure](./edc-configure/fedora-configure.sh)

## Development tools

- neovim
- terminal - default (Pytxis)
- git/github
  - To authenticate with github, it is easiest to install gh CLI. Follow the [docs](https://github.com/cli/cli/blob/trunk/docs/install_linux.md#dnf5) for latest installation guidance.

## System

- Proton Mail - available through flatpack
