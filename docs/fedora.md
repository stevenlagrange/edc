# My Fedora edc

Home Setup:
- Fedora Linux 44 (Workstation Edition) 

This document supports the bash installation scripts provided in [scripts](./scripts/fedora-configure.sh)

## Development tools

- neovim
- [ghostty](https://ghostty.org/docs/install/binary)
- git/github
  - To authenticate with github, it is easiest to install gh CLI. Follow the [docs](https://github.com/cli/cli/blob/trunk/docs/install_linux.md#dnf5) for latest installation guidance.
- [nvm](https://github.com/nvm-sh/nvm#installing-and-updating)
  - After install, `nvm install --lts` to get latest long term support version.
- [podman](https://podman.io/docs/installation#installing-on-linux) - installed by default
- [devcontainer](https://github.com/devcontainers/cli#npm-install)
